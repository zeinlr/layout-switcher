# LayoutSwitcher

Небольшая утилита для Windows, которая исправляет текст, набранный не в той раскладке (`ghbdtn` -> `привет`).

Работает только по нажатию горячей клавиши — сама по себе в текст не лезет и ничего на лету не переключает.

## Как работает

- Нажимаешь **F8** (по умолчанию) — текст исправляется:
  - Если слово или фраза **выделены** — исправляет выделенное.
  - Если курсор просто стоит в конце слова — исправляет последнее слово.
- После замены сразу переключает язык ввода в системе, чтобы можно было дальше печатать.
- Сидит в трее, ест около 10 МБ памяти.

## Использование

1. Скачать `LayoutSwitcher.exe` из [Releases](../../releases).
2. Запустить.
3. Чтобы поменять хоткей или поставить в автозапуск — кликнуть правой кнопкой по иконке в трее (или запустить exe ещё раз).

## Запуск из исходников

Нужен Python 3.10+:

```bash
git clone https://github.com/zeinlr/layout-switcher.git
cd layout-switcher

pip install pystray pillow pyinstaller
python main.py
```

Сборка exe:
```bash
python build.py
```
